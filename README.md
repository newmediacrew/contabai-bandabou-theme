# Bandabou Curaçao Theme

Standalone WordPress theme for Bandabou Curaçao. Pairs with the [Contabai plugin](https://github.com/newmediacrew/contabai-plugin), which supplies the search, listings and guest pages.

## Requirements

- WordPress 7.1 or newer
- PHP 8.3 or newer
- The Contabai plugin 1.2.33 or newer

## Overriding plugin views

Copies of plugin views live in `contabai/`, using the plugin's view path. The theme owns these copies: after a plugin update that touches a public view, check them by hand.

## Settings

Branding · Hero · Top bar · Typography · Background · Contact · Socials · Updates · Advanced

Fonts are self-hosted: no requests to Google.

## Updates

New versions appear in **Dashboard → Updates** like any other theme. **Development mode** (Advanced tab) switches this off for a development copy.
